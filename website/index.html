FAQ

Common questions.

Does it require a cloud account?

No. Core features run entirely on your machine using a local SQLite database. AI and Google Calendar features only need keys or accounts when you opt in through Settings.

Which AI providers are supported?

NVIDIA NIM (recommended, has a free tier), OpenAI, Anthropic Claude, Groq, and Google Gemini. You pick one and paste your key — nothing else needed.

Is my data private?

Activity data, notes, diary entries, and settings are stored in a local SQLite file. Only AI summary calls and music streaming touch the internet. Incognito mode pauses all tracking instantly.

Does it work on Mac or Linux?

Windows 10/11 is the primary target because activity tracking, OCR, and media detection use Windows-specific APIs. Mac/Linux builds may have reduced features.

How does the Diary work?

The diary creates per-day entries using only that day's activity, LeetCode data, and music history. Today never gets a summary — it auto-generates at midnight for yesterday, keeping everything clean and isolated.

Is YouTube music legal to use?

Atheletia uses the YouTube embedded player, similar to how YouTube Music works in a browser. It streams content you could watch on YouTube normally. No audio is downloaded or stored.
